# Laya 原理与本 skill 的复刻方式

## Laya 到底是什么

Laya（Convai）是一个 **System 1 决策模型**：非自回归、一次前向、输出校准概率。
它解决的是"用一个小模型替掉 LLM 做高频结构化小判断"的问题——分类、打分、是否判定、
模型路由、护栏等。核心卖点是 **33ms/问、0 输出 token、不会幻觉出你没定义的标签**。

它的三个关键机制：

| 机制 | 原版实现 | 本 skill 复刻方式 |
|---|---|---|
| 结构化决策瓶颈 | 固定题型（choice/score/noul）+ 固定答案空间 | 同款 schema 格式（见 `question-library.md`） |
| 校准式置信度 + 弃权 | RLCD 训练出的 proper-scoring 校准概率 | 大模型**自我报告置信度**作代理 + `min_confidence` 闸门 |
| 预测与行动分离 | 概率喂策略，策略才触发动作 | 协议强制：命中高危闸门必须停下确认 |

## 为什么不复用原版包

原版 `laya` 包需要：`pip install torch`（CPU 版也大）、首次 `predict` 联网从 HuggingFace
下载 600MB~1.7GB 权重。在离线 / 受限网络 / 轻量环境里根本跑不起来。

本 skill 的取舍：**把"模型"换成"加载 skill 的大模型自己"**。大模型本来就有判断能力，
缺的只是 Laya 那种"固定输出格式 + 可门控置信度 + 升级机制"的**纪律**。本 skill 用一份
纯标准库脚本（`laya_engine.py`，零 pip 依赖）把这套纪律补上。

## 校准的诚实说明

原版用 RLCD（强化学习训练校准决策）让模型"如实报概率"才能拿到最大奖励，因此它的
`answer_confidence` 是跨题型可比、可设阈值的。本版用大模型的自我报告置信度，
**它没有经过 proper-scoring 校准训练**，会存在以下偏差：

- 大模型普遍**过度自信**：标 0.9 的答案未必真有 90% 对。
- 自我报告在不同题型/不同 prompt 下**尺度不一致**。

应对办法（务必遵守）：
1. 默认把 `min_confidence` 设到 **0.6~0.7**，而不是 0.5，给过度自信留缓冲。
2. 高 stakes（涉钱、权限、不可逆）一律走 `human` 闸门，不拿置信度当唯一依据。
3. 上线前用真实标注数据人工抽查一批，确认你的置信度分布与准确率大致匹配。

## 选择性预测（最有用的部分）

即使置信度不完美，"挑出低置信样本交给贵通道、高置信自动处理"依然成立：
- 高置信 → 直接自动化（打标、分流、预筛）。
- 低置信 → 升级完整推理（System 2）或人工。
这把"大模型全量慢推理"降级成"大模型当快判引擎 + 只在模糊处求助"，正是 Laya 的精髓。
