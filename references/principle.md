# Laya 原理与本 skill 的复刻方式

## Laya 到底是什么
Laya 是 Convai 开源的 **System 1 决策模型**（约 3.22 亿参数，非自回归、单次前向，
输出校准概率）。它专门替代「LLM-as-a-judge」：把"判断/分类/路由/评分"这类**高频结构化小决策**
从慢且贵的自回归 LLM 里剥离出来，用一个快、便宜、可校准的专用引擎做。核心三件事：

1. **固定答案空间的决策瓶颈**：题目与可选答案预先固定，模型只输出受限结构（不是自由文本）。
2. **校准置信度 + 弃权**：每条答案带校准概率，低置信直接「我不知道」(abstain)，交回更强的模型或人。
3. **预测与行动分离**：它只判级，不执行；高风险动作由上层闸门拦截。

## 本 skill 复刻了原理，而非模型本身
原版需要装 `laya` 包 + torch + 下载 HuggingFace 权重（沙箱里权重下载被墙、还要多 GB CUDA）。
本 skill **抛掉这些外部依赖**，把上面三条原理搬成协议 + 纯标准库脚本：

- **结构化决策瓶颈** → `schema.json`：固定 choice / score / noul 题型，答案空间预先锁定。
- **校准置信度 + 弃权闸门** → `min_confidence`：低于阈值的字段 `abstain`，绝不静默采用。
- **预测-行动分离** → 路由只给「判级 + 升级建议」，真正执行必须由人工/二次确认触发。

**谁来当引擎？** 加载本 skill 的大模型自己当 System 1 引擎：按协议产出结构化 JSON 答案+
置信度。脚本只负责**协议强制 + 归一化 + 闸门 + 路由 + 共识 + 审计**，不生成判断。
内置**离线启发式兜底**（关键词/CJK 二元组），使无网络、无大模型时也能跑（baseline / CI / 批量）。

## 专家团扩展（v2.0）
在原理之上，本 skill 把"单引擎"扩成"**1 中枢 + N 专家**"：
- 中枢负责路由（route）、闸门、共识（consensus）、审计（audit）。
- 每个领域专家是一个独立 skill（`expert-<id>`），自带 `schema.json`(出题) 与
  `SKILL.md` 里的「System 2 深度推理协议」(弃权/高危时做完整分析)。
- 多专家结论经 `consensus` 融合：任一人审 → 团队人审；否则 System 2；否则 pass。

## 诚实的边界（必读）
- 原版置信度由 RLCD 真·校准；本版是**大模型自我报告**，可能过于自信。因此：
  - `min_confidence` 建议设 **0.6~0.7**，高 stakes 直接走高闸门。
  - 任何不可逆/越权/出网/金钱/发布动作，**禁止自动执行**，一律升级人工。
- 离线启发式仅是 baseline，不能替代大模型判断。
- 专家 schema 与 System 2 提示词需按你的业务持续打磨（见 `schema_gen.py` 与 `expert-team.md`）。

## 与原版的能力对照
| 维度 | 原版 Laya | 本 skill |
|------|-----------|----------|
| 决策模型 | 专用 322M 模型 | 加载 skill 的大模型（当引擎） |
| 依赖 | laya + torch + 权重 | 零（纯 stdlib） |
| 联网 | 需下载权重 | 不需要 |
| 题型 | choice/score/noul | 同（兼容） |
| 校准 | RLCD 真校准 | 自我报告（建议高阈值） |
| 升级 | abstain 回退 | abstain + 高危闸门 → System2/人工 |
| 专家团 | 无 | 1 中枢 + N 专家 + 共识 + 审计 |
